no excluir corridas lentas. Tamaños definitivos dependen de mediciones del
invitado/store y piloto, no del espacio libre del host solamente.

## Faltantes y aceptación observable

Faltan instrumentos Glance específicos, protocolo propio, piloto común autenticado,
verificación funcional A/B/C/D actual y orquestación reversible Glance+Placement
ensayada. Implementar carga HTTP con ledger, streaming y recuperación; conservar
estado parcial y no contar HTTP fallido como éxito. Crear protocolo integrado
independiente y gate D obligatorio. Sólo iniciar campaña oficial con protocolo
congelado tras piloto, configuración efectiva, todos los gates pertinentes,
lock exclusivo, recursos suficientes y restauración comprobada. Un test local
o una implementación de herramienta no satisface estos gates.
